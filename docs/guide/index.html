建议体验顺序

  1. 打开软件，确认当前外观保持不变。
  2. 从鼠标、壁纸、图标开始，先选择和预览，再通过底部“应用当前主题”执行。
  3. 测试主题组合、资源管理器背景及恢复操作。
  4. 可选模组一次先启用一个，打开它的目标程序，再判断是否需要。
  5. 在清单记录结果并导出 JSON；试完后用“恢复使用前外观”恢复本分支记录的基线。

与主线的区别

已移除 Seelen Dock、顶部工具栏、Mac 桌面切换与 Seelen 专属主题入口。安装包没有 Seelen 引擎和服务。已有开源媒体/界面组件的源码与许可证继续保留。

默认安装目录是 ThemeStudio-NoSeelen，数据在 %LOCALAPPDATA%\ThemeStudio-NoSeelen。安装和打开不会自动替换外观。本分支禁止覆盖主线目录，不接收主线更新。两版操作的是同一个 Windows 桌面，请先恢复再切换体验。

Windhawk 不能与其他版本的引擎同时启用；已有其他引擎运行时会给出提示。本次没有替你更改当前桌面。

适用范围

Intel / AMD 64 位 Windows。基础功能需 Windows 10 19041+、.NET Framework 4.8 和 WebView2；资源管理器外观入口需 Windows 11 build 22621+。缺少 WebView2 时安装向导从微软下载，已有运行库时跳过。

图标功能针对 .lnk / .url 快捷方式；部分程序自绘鼠标不跟随系统方案。内置主题使用静态壁纸，动态素材可自行导入。桌宠需自备主程序。不同模组与 Windows 控件版本的兼容性需逐项体验。
