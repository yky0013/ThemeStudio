01 / INSTALL

安装到你选择的位置

将 ThemeStudio-0.4.0-Windows-x64-Setup.exe 复制到目标电脑，双击运行。使用 Windows 10（2004 / 19041 或更新版本）或 Windows 11，推荐 Intel / AMD 64 位电脑。安装程序会检查 .NET Framework 4.8；缺少 WebView2 时，使用包内的微软官方引导安装器联网补齐。

  1. 阅读安装说明。 点击“下一步”进入安装目录选择。
  2. 选择安装路径。 可直接使用默认目录，也可点击“浏览”选择，例如 D:\Apps\ThemeStudio。安装与启动都会弹出 Windows 管理员授权窗口，请核对程序名称后选择“是”。
  3. 选择快捷方式。 可按需要创建桌面快捷方式，开始菜单会包含程序、教程和卸载入口。
  4. 点击“安装”。 首次补齐运行库时可能需要稍等。完成后可以启动程序或打开本教程。
程序目录与素材目录分开保存。修改安装路径不会改变素材和备份的位置：%LOCALAPPDATA%\ThemeStudio。

DESKTOP STYLES / MOTION

Windows 与 Mac 风格，两种桌面任选

打开“桌面风格”，选择 Windows 或 Mac 风格，再点击“切换为…”。Windows 使用原生任务栏和开始菜单；Mac 风格启用 Seelen 的底部悬浮 Dock 与顶部工具栏，系统仍然是 Windows。切换桌面风格不会替换当前壁纸。

10 套模板都有动态版

在“一键主题”选择“动态壁纸”或“静态壁纸”。点击卡片可预览，动态版是原插画的 12 秒静音循环运镜与柔光动效，预览播放器可以暂停。点击应用后才修改桌面。“恢复上一次应用”会恢复上一套壁纸、指针与图标；上一套是动态壁纸时会继续播放。

“壁纸与视差”区域也可导入 GIF、动态 WebP、APNG 和视频。关闭视差仍会播放动图，可暂停、继续或停止。静态版通过 Windows 显示，不运行后台播放器；动态版关闭设置窗口后继续播放。

THEME PACKS / UPDATES

导入一个数据包，获得一整套主题

  1. 在“一键主题”点击“导入主题数据包”，选择 .tspack 或 .zip。
  2. 校验完成后套装加入列表，可以先预览，再点“一键应用”。只有壁纸的套装会保留现有鼠标和图标。
  3. 预览窗口的“导出完整套装”会打包壁纸、视频、鼠标、图标和说明文件，便于分享或制作自己的主题。

同一数据包重复导入不会产生重复卡片。同一套装的新版会更新卡片，旧素材保留供恢复使用。主题素材保存在 %LOCALAPPDATA%\ThemeStudio\theme-packs，重启和升级后继续保留。

制作自己的数据包

最方便的方法是导出一套现有主题，用 ZIP 工具解压，修改素材以及 theme.json 中的 name、id、version。重新压缩时，把 theme.json 放在压缩包根目录，不要多套一层文件夹。修改同一主题时保留 id 并增加三段数字版本号。

最小套装只需一张 wallpaper.jpg 和以下 theme.json；可选动态壁纸字段 animatedWallpaper 指向 MP4。图标和完整 17 状态指针的格式可参考导出的套装。

{"schemaVersion":1,"id":"my-theme","version":"1.0.0","name":"我的桌面","wallpaper":"wallpaper.jpg"}

单包上限 512 MB，解压后 1 GB、2048 项；不接受程序、脚本、链接、外部路径或加密 ZIP。Windows 原生 .themepack 和旧“导出配置”JSON 不属于该格式。

检查更新与离线更新

左侧“应用更新”→“检查更新”，有可用正式版时可以阅读说明、下载并校验，再点击“关闭应用并启动安装”。按安装向导完成更新后重新启动。下载过程中可取消；下载完成不会自动安装。

也可以点击“选择离线更新包”，选择较新版本的 ThemeStudio-版本号-Windows-x64-Setup.exe，将配套 .exe.sha256 文件放在同一文件夹。程序会复制并校验安装包，安装前再次确认文件未变化。

当前 GitHub 发布源尚未提供匿名可读的正式版本，可能显示“更新源暂未提供可公开访问的正式版本”。此时可以使用离线安装包更新。升级沿用原程序目录，并保留素材、套装与恢复记录。

02 / WORKSPACE

所有设置，在同一页完成

左侧导航可定位到“桌面图标”“鼠标指针”“壁纸与视差”“Seelen 外观”和“Windhawk 模组”。右上角“图文教程”可随时打开本说明，也可切换深浅色。导航只是页内定位，已经编辑的项目不会因切换区域而丢失。

“保存草稿”记录 Seelen / Windhawk / 视差的组合参数；图标和鼠标在各自区域点击“应用”后才改变 Windows。图标素材和指针方案保存在本机资源库。

03 / DESKTOP ICONS

普通图片，直接变成桌面图标

  1. 勾选快捷方式。 在“桌面图标”中选择一个或多个项目，可先输入名称搜索。
  2. 点击“选择图片”。 支持 PNG、JPG/JPEG、WebP、BMP、GIF、TIF/TIFF 和 ICO。图片会自动处理为多尺寸图标；无需先转换、导出或找到 ICO 文件。
  3. 检查右侧预览。 确认图片及“已选”数量，再点击“替换已选 N 个图标”。每个项目可以对应不同的图片，箭头连接当前图标与新图片；未指定图片的项目不能应用。
  4. 为不同软件用不同图片。 点击项目后点击右侧资源图片，或把资源库图片拖到目标卡片，也可使用每个项目下方的图片选择框。保存对应关系后可以一起应用。

动态图使用第一帧。默认等比保留图片并透明补齐，支持透明 PNG；单文件不超过 32 MB、图片不超过 4000 万像素。素材会复制到本机库，原图片移动或删除后，已应用图标仍能使用。

本版修改 .lnk 软件快捷方式和 .url 网页/游戏快捷方式。不修改“此电脑”“回收站”、文件夹或 EXE 内部图标。本版程序启动时会请求管理员授权，用于修改公共桌面项目；失败项会显示实际原因，成功和失败分别记录。

04 / MOUSE POINTERS

配置鼠标的 17 种状态

  1. 选择方案。 可使用“当前系统指针”“Windows 默认”或已保存方案。
  2. 替换一个状态。 点击“普通选择”“文本选择”等状态，再点“选择指针文件”，导入 .cur 或 .ani。
  3. 或导入整套文件夹。 程序按文件名匹配角色，匹配不到的状态保留原值；应用前逐项查看。
  4. 保存或应用。 输入方案名后可“保存指针方案”。准备好后点击“应用鼠标指针”，系统才会改变。

部分游戏、绘图软件和网页会使用自己的光标，不一定跟随 Windows 系统方案。

05 / RESTORE

不喜欢新效果，恢复即可

恢复图标

展开“图标备份与恢复”，找到对应时间和数量，点击“恢复这次替换”。如果之后又替换过同一项目，先恢复较新的批次。

恢复鼠标

点击“恢复上次鼠标设置”，返回上一次应用前的方案。程序会核对当前设置，避免覆盖其他软件后来做的修改。

如果提示“已被其他操作修改”，先核对当前设置再操作。不要直接删除素材库来恢复外观；删除素材只会让 Windows 找不到正在引用的文件。

07 / UNINSTALL

卸载程序，保留素材与备份

  1. 需要恢复原外观时，先恢复。 在图标与鼠标区域恢复，并在壁纸区域停止恢复、在运行组件区域停用 Dock/工具栏及模组。
  2. 关闭主题工作室。 等待正在进行的应用或保存结束。
  3. 选择任一卸载入口。 开始菜单 → 桌面主题工作室 → 卸载；或 Windows 设置 → 应用 → 已安装的应用，找到“桌面主题工作室”后卸载。
  4. 确认卸载。 程序文件、开始菜单和安装器创建的快捷方式会被移除。

%LOCALAPPDATA%\ThemeStudio 默认保留；重新安装后可继续使用其中的素材和备份。共享的 Microsoft WebView2 运行库也保留，其他应用可能仍在使用它。卸载程序不会自动撤销已应用的图标或鼠标。

本地备份针对当前电脑和账户。请先恢复再自行整理数据目录，不要把另一台电脑的备份覆盖过来。

08 / HELP

常见问题

其他电脑需要安装 Python、Node.js 或旧工作台吗？
不需要。安装包包含程序和后端。需要受支持的 64 位 Windows、.NET Framework 4.8；WebView2 缺失时由安装包补齐。
选择了图片，为什么桌面还没变？
选择图片只准备素材。请勾选目标并点击“替换已选 N 个图标”。如果 Explorer 尚未刷新，可在桌面按 F5。
找不到想改的图标？
先点“刷新桌面列表”，清除搜索框。本版只列出软件/网页快捷方式，系统特殊图标和普通文件夹不在范围内。
显示“没有写入权限”？
安装和启动程序时请接受 Windows 管理员授权。若仍失败，请核对该快捷方式的特殊文件权限与错误提示，保留备份，不要删除资源库。
导出文件保存在哪里？
页面成功提示会显示完整路径，默认在 %LOCALAPPDATA%\ThemeStudio\exports。
安装后启动失败或运行库安装失败？
保留错误提示和日志。程序启动日志位于 %LOCALAPPDATA%\ThemeStudio\diagnostics。安装日志位于 %TEMP%，文件名以 Setup Log 开头，会记录运行库执行结果；不要删除自己的素材和备份来排查。
