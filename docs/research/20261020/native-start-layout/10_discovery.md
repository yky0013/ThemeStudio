# Local discovery checkpoints

Research date: 2026-10-20. All filesystem/registry checks were read-only; the only generated files are inside this research folder.

## Checkpoint L1 — Seelen contract

- Source: `vendor/runtime-sources/Seelen-UI-2.8.6/src/background/exposed.rs`, `get_native_start_menu`.
- Current behavior: writes `%SEELEN_COMMON%/cache/start-layout.json` by running `Export-StartLayout -Path '<path>'`, deserializes `StartMenuLayout`, then expands environment variables in every `desktopAppLink`.
- Rust model: `StartMenuLayout { pinned_list: Vec<StartMenuLayoutItem> }`, with `desktopAppLink`, `packagedAppId`, `desktopAppId`-style enum variants, and `secondaryTile` support in the source model.
- Implication: the replacement must call the export operation without `UseDesktopApplicationID` so that ordinary Win32 pins remain `desktopAppLink` entries, then keep Seelen's existing environment expansion.
