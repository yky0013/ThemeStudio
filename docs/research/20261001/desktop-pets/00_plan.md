# ThemeStudio 桌宠来源调研计划（2026-10-01）

## 边界

本次只核验 ThemeStudio 目标主题可对应的桌宠来源、运行时和可导入交付形式。研究对象为鸣潮、原神、崩坏：星穹铁道、绝区零、明日方舟、蔚蓝档案、战双帕弥什、第五人格、Chiikawa、Milk Mocha；若没有可核验的一手来源，记录缺口而不补猜测。

## 证据规则

- 一手来源优先：官方发行页/官方仓库/作者仓库/平台官方 Workshop 页面。
- 搜索结果只作为发现线索；结论必须回到可直接访问的来源页或仓库文件。
- 每次页面/仓库抓取后立即追加到 `20_sources.md`；阶段性发现追加到 `10_discovery.md`。
- 明确区分“官方发布”“社区作者内容”“仅有搜索命中/未核验”。
- 不下载、运行或安装桌宠与运行时，不向外部发送消息。

## 目标交付

`90_synthesis.md` 提供：主题级来源目录、来源 URL、作者/发行属性、可观察交付格式、运行时要求、是否可直接作为 ThemeStudio `.tspack`/`.zip` 的安全判断，以及风险与缺口。ThemeStudio 本地包格式仅用现有源码和文档作兼容性参照，不宣称外部桌宠可直接导入。
