# ThemeStudio 0.6.0

本版从保留的 0.5.0 源码恢复后另存。原 0.5.0 两个安装程序和增量源码包保留，先单独提交恢复的源码，再提交本版新增功能。

文件资源管理器使用固定 Windhawk File Explorer Styler 1.6 的 16 个非空主题预设。独立应用操作只改变这个模组的 theme 与启用状态，应用前记录，失败后尝试恢复；中断记录可以重试恢复。通用模组应用不再因未选择该模组而停用它。恢复检测外部修改，不覆盖其他来源的变更。Windows build 22621 是本版入口的兼容性限制，取自 DWM backdrop API 的可用范围，并非宣称上游所有 XAML 功能具有完全相同的最低版本。

桌宠使用外部原运行时：通过本地原生文件选择器登记 EXE 主程序，检查 PE 文件头，保存绝对路径和 SHA-256。导入、查询和移除记录不会启动程序或修改原文件。启动前重新核对哈希，通过 Explorer 打开已登记的本地快捷方式，不向桌宠传入网页提供的命令参数。状态只检测登记主程序路径，启动器的子进程可能无法识别。角色模型/Steam 工坊订阅仍需在其原引擎中导入。此版本未把第三方桌宠重新打包成内置引擎。

内置十个配套 MP4 共 27,672,629 字节被移除；原始 0.5.0 文件不受影响。内置套装默认静态，套装版本升为 2.1.0，用户自己导入的动图、视频和含 MP4 的主题包继续支持。主题库增加直接打开壁纸导入的入口。

验证会分别记录类型检查、自动测试、原生启动/预览、独立编译和预设读写。本轮不自动应用用户真实桌面外观，也不启动下载的第三方桌宠，因此实际 Windows Explorer 的视觉覆盖和第三方桌宠互动不属于已通过验证的结论。

构建工具 Inno Setup 6.7.3 通过官方签名校验后按官方 `/PORTABLE=1` 模式放入项目 `.tools/`；没有全局安装编译器。发布包不包括 QA 目录、用户数据、编译缓存或开发专用诊断 EXE。
