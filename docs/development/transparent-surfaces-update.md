# 0.6.3 / 0.5.3：未选中区域与空预览透明背景修订

用户于 2026-10-05 的截图显示，文件列表已有主题背景，空预览、表头、滚动条和底部仍被浅色底板覆盖。需求是空预览与文件列表保持一致，其他普通状态区域显示背景，文字清晰，并保留既有选中/悬停效果。另要求修复工作区的天选姬指针恢复入口。

## 原因与修复

旧版把文件列表内层 DirectUI 与预览宿主列入作用域，但空预览和部分公共区域由 DUIViewWndClassName 下的外层 DirectUI 绘制；只追踪 BeginPaint/CreateCompatibleDC 也会遗漏 uxtheme 缓冲画布。静态提示的 CTLCOLOR 返回了实色笔刷，即使擦除背景时画过图片，标签仍可再次盖住背景。

原生模组 1.2.0 增加外层 shell DirectUI 及其容器作用域、GetDC/GetDCEx/ReleaseDC 和 BeginBufferedPaint/EndBufferedPaint 配对追踪，并在提交前恢复 GDI 绘制区的 alpha，覆盖真实带 alpha 混合和取消提交的测试；把静态提示改成透明笔刷，同时绘制同坐标背景和设置清晰文字色。补齐表头两端、状态栏、普通滚动条轨道及旧版 DrawThemeText/不透明文字绘制入口。滚动条保留可见拖动柄和箭头；主题绘制的选中/悬停调用原函数，嵌套的白色填充也不会被背景替换。

预览处理只作用于 shell 容器与它直接拥有的占位标签，不穿过文档预览处理器更改 PDF、图片、RichEdit 或其他预览内容。XAML 根部显示已经调暗的主题图片，导航/工具栏/详细窗格的普通底板使用透明色。应用内预览同步移除重复遮罩，所有普通区域使用相同背景和浅色文字。Windows 独立 XAML 岛的裁切仍由对应根控件决定，不能据此保证各 Windows 版本顶栏与 Win32 内容区完全像素对齐。

天选姬恢复入口的原中文 BAT 内含 UTF-8 脚本名，在本机 CMD 的 936 代码页下解析为错误路径。两个 BAT 现在都采用 ASCII 内容、CRLF 换行并调用英文脚本名，保留真实失败退出码。中英文 PS1 入口共用一个实现；验证全部文件后才写入设置，保存原设置，恢复 OEM 定义的 13 种图案，其余 4 种角色回归 Windows 默认。仅修改指针；不重置壁纸和桌面图标。

## 已完成验证与边界

真实系统上：中文和英文 BAT 执行成功；Windows 实际加载箭头与预装 ASUS ANI 第 0 帧在黑/白底上渲染的 SHA-256 完全一致；缺失文件测试在修改前失败，只读验证保持注册表不变。

隔离 Win32 测试覆盖：整窗背景坐标、局部重绘、外层 DUI 空预览、表头、滚动条普通/悬停状态、原选中状态及其嵌套白色绘制、透明静态文字笔刷、真实 uxtheme 缓冲画布的非零起点绘制与回收、预览处理器排除、文字颜色和重复绘制 GDI 资源寿命。实际 Windhawk 编译保持模组 disabled，不改变用户系统模组。

本轮不以应用内预览或隐藏测试窗口代替实际 Explorer 截图验收。真实 Explorer 全窗口现场效果、安装/卸载生命周期尚未验证，两个发布保持 prerelease。每个版本的具体构建、测试、安装包哈希见对应 verification JSON。
