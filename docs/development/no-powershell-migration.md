# 终端语言迁移（2026-10-20）

本次分别更新 NoSeelen Trial2、0.6.5 和 0.5.5，保留各系列原有的功能、素材、数据目录和安装身份。

- 主程序继续使用 C#，前端 TypeScript，业务后端使用打包的 Python。
- 构建、依赖准备、打包和验证入口改为 Python：tools/studio.py、tools/qa.py。
- 原厂指针恢复使用 C# EXE，保留 13 个原厂映射、4 个默认角色及备份，新增失败回滚。
- 两个 Windhawk 模组的内部网络/授权实现使用 C# 原生操作工具，通过 WMI 和原生 EXE 完成，保留用户点击、UAC、等待和结果检查。网络重置超时不强杀恢复进程，并阻止并发操作。
- 常规 0.5/0.6 系列的 Seelen 使用同版本源码中的原生 COM 接口导出开始菜单布局；不再启动 PowerShell 或载入其运行时。自编译的引擎不是上游原签名 EXE，文件哈希与构建来源单独记录；306 个官方静态资源及原有签名校验保持不变。

安装包不携带 PowerShell 脚本或解释器。用户主动选择打开 PowerShell 终端、运行自己的脚本等可选功能保持兼容，不属于本次替换的内部实现。

原厂恢复入口为 AsusCursorRecovery.exe；两个 BAT 入口只转交给 EXE。备份位于 %LOCALAPPDATA%\ThemeStudio-CursorRecovery\backups。
只读检查支持 --verify-only；--quiet --json-output 可用于自动验证。升级安装只移除两份被替代的旧恢复脚本，不移除用户素材或备份。

旧开发脚本在 docs/history/powershell-tools 留作历史证据，不再参与构建或随安装包分发。历史一次性清理/发布流程不重新执行。
常规 0.5 与 0.6 仍共享原主线安装身份，不应并排安装；NoSeelen 保留独立身份。没有移植其他系列的功能来改变各系列范围。

验证结果以 no-powershell-verification.json 为准。现有前端/后端回归、只读原生窗口/预览、原生恢复检查、禁用状态下的模组编译和静态资源校验均单独记录。
安装/卸载、实际网络切换、WindowsApps 权限更改及全桌面视觉效果，只有完成现场操作后才能标记通过；本次不会为了验证而中断用户网络或修改系统目录权限。
