# ThemeStudio 0.3.0

新增 10 套一键主题：鸣潮、战双帕弥什、原神、第五人格、线条小狗、崩坏：星穹铁道、绝区零、明日方舟、蔚蓝档案、Chiikawa。

每套包含一张同人壁纸、缩略图、12 个多尺寸 ICO 图标和 17 状态 CUR 指针。图片由内置 image_gen 工具生成，提示词、生成来源和成品哈希见 `assets/wallpaper-provenance.json`；图标和指针构建源为 `tools/build-template-assets.py`。作品名、角色名归各自权利人，生成图不作为官方素材。

模板可选择是否应用鼠标与匹配的桌面图标。应用先校验素材，快捷方式使用现有哈希冲突检查和备份逻辑；失败时恢复已完成的步骤。静态壁纸和模板历史持久化保存，重启后可恢复。如果壁纸、鼠标或快捷方式已被别的程序修改，恢复会保留冲突现场。

修复设置页 CSP 漏放行 `https://media.theme-studio.invalid` 导致导入图片和视频无法预览的问题。仍限制为固定的本地虚拟域，不放开任意网络源。

运行内存优化：预览组件接近可视区域时才初始化；离开区域或窗口隐藏时暂停播放；Seelen 运行状态只在可见区域每 15 秒读取；Windhawk 卡片延迟创建；窗口最小化后通过 WebView2 TrySuspendAsync 暂停并在恢复时 Resume；清理过期的图标预览缓存。图片壁纸关闭视差后使用 Windows 原生静态壁纸，避免常驻网页播放器。

打包优化：使用约 1.8 MB 的 Microsoft WebView2 Evergreen Bootstrapper 替代完整运行库（缺少 WebView2 的机器安装时需联网）。保留 Seelen 和 Windhawk 的 x86/x64 编译及运行能力，移除未被本应用使用的 VSCodium 编辑器、clangd 语言服务器、ARM64 交叉编译目标。原始完整上游源码与许可证仍保留。

应用、安装器及快捷方式统一使用新的紫蓝渐变窗口图标。安装器完成后用 runascurrentuser 启动需要管理员权限的主程序，修复 740。

验证边界：原生 WebView2 中逐套验证 10 张主图、10 张缩略图、本地视频、实际预览区域及暂停恢复。自动测试在临时目录真实修改并恢复快捷方式；壁纸/系统指针的修改接口在单元测试中模拟。自动审批拒绝了会临时改变用户当前系统壁纸/指针的测试，因此没有将其标为全局端到端实测。当前桌面不会因为构建而自动套用任何主题。
