# ThemeStudio 0.4.0

主题库支持 `.tspack` / `.zip` 数据包导入、完整套装导出、预览和一键应用。数据包中的 `theme.json` 描述静态壁纸、可选 MP4、17 状态鼠标、图标与匹配关键词。可导入只有壁纸的套装；只应用实际包含的配件。格式见 `docs/theme-pack-format.md`。

包先在用户数据目录的临时区解压并校验，再原子更新索引。拒绝目录穿越、Windows 特殊路径、链接、可执行文件、重复名称、缺失素材和超限数据；同包去重，同 id 的新版替换卡片并保留历史素材。素材通过独立本地虚拟域显示；导入文件无需常驻原位置。

应用更新提供手动检查 GitHub 正式版、显示更新说明、下载进度、取消、SHA-256/大小校验和显式安装交接。离线更新接受较新版本安装 EXE 与同目录 `.exe.sha256`；校验后复制到独立缓存，安装前再次核对哈希与原生产品版本信息。程序退出后交给现有 Inno Setup 安装器，沿用同一 AppId 与原目录；用户数据独立保存。

在线来源固定为 `yky0013/ThemeStudio`，不含凭据。2026-09-29 匿名 API 返回 404，暂时没有可公开读取的正式发布源。检查更新会如实显示不可用并指向离线更新；不会把连接失败说成“已是最新”。本版是本地交付，未修改 GitHub 可见性或发布状态。后续发布公开正式版本、上传精确命名的安装包与校验信息后，在线入口才能面向其他使用者工作。
