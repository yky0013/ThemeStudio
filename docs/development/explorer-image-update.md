# 资源管理器图片主题修订（2026-10-04）

0.6.0 修订为 0.6.1，0.5.0 同步修订为 0.5.1。原安装包保留。

## 行为

- 内置目录和安装包不再包含绝区零、明日方舟、蔚蓝档案，保留其余七套。已导入的数据包仍保留。
- 一键应用默认勾选资源管理器，使用同一主题的静态壁纸，动态套装使用静态封面。
- 主题预览弹窗和资源管理器页面都有实时图片预览，可见度为 10–70%。预览不应用系统设置。
- 原生文件列表使用独立 Windhawk 绘制组件；顶部、主文件夹和图库使用原 File Explorer Styler。标题栏保存并恢复原 DWM 颜色。
- 每次应用保存两个组件的原设置与启用状态；失败回滚，外部修改发生冲突时拒绝覆盖，支持依次恢复之前的主题。
- 0.5.1 保留 0.5 系列的配套动态素材；0.6.1 沿用 0.6 系列的静态内置素材和外部动态导入方式。

## 验证范围

验证记录保存在 `qa/`：前端构建和类型检查、Python 事务测试、Windhawk 两组件实际编译及设置往返、隔离 Win32 窗口的 GDI 图片绘制/文本颜色/选择保留/部分重绘/资源释放，以及桌面容器的只读预览测试。

隔离绘制测试和应用内预览不等于用户当前 Explorer 的现场视觉验收。当前进程没有管理员权限，本轮不提权、不重启 Explorer；目标 Windows build 的完整效果仍需安装后现场核验。界面分别显示配置启用与组件载入状态，不将两者当作视觉验收。

## 源码来源

原生 GDI 绘制依据 [Maplespe ExplorerBgTool](https://github.com/Maplespe/explorerTool) 的 MIT paint/DC 跟踪方法，使用已有 Windhawk 生命周期代替 COM/BHO 注册。许可证在 `licenses/ExplorerBgTool-MIT.txt`，第一方源码证据在 `docs/research/20261004/explorer-background/`。Windhawk Styler 继续使用项目锁定的原始源码。
