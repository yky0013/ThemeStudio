# 0.6.2 / 0.5.2：统一应用与两级恢复

用户于 2026-10-05 提供真实 Explorer 截图：右侧预览窗格出现白色背景，导航栏未选中区域与主题不一致；多个应用/恢复入口还会造成指针恢复记录互相冲突。用户明确选择将鼠标、图标、壁纸、资源管理器和桌面外观设置收拢到一个应用入口。

## 交互

- 各区域只选择、导入、保存资源和预览。主题卡片与主题弹窗负责选择，资源管理器页负责调整。
- 底部只保留一个“应用当前主题”，提交本次选择的整套设置。自定义图标或指针会覆盖同次主题包中的对应配件，避免重复写入。
- 桌面风格、Seelen 配色、Windhawk 模组同样加入统一提交；桌宠是外部应用的启动入口，不加入外观恢复事务。
- “恢复上一次”按整次提交撤销；“恢复使用前外观”使用独立保存的初始外观。初始恢复本身也能通过“恢复上一次”撤销。
- Windows 10 保留原有壁纸/图标/指针能力，资源管理器图片样式仍要求 Windows 11 22H2+。

## 恢复与迁移

统一事务保存前后快照、资源校验值、初始副本以及未完成操作标记。重复点击和第二实例不能覆盖未完成记录；发生错误会尝试整套回滚，并保留失败记录。

初始外观不会随之后的主题应用覆盖。壁纸、CUR/ANI 和快捷方式保存可校验副本。新用户保存首次应用前的状态；旧用户从现存历史备份重建，并在界面标明来源。无历史证据的部分按升级时现状保存；无法凭空还原已经丢失且没有备份的状态。

旧版恢复会识别由本软件产生的已知指针状态，以及相同 CUR/ANI 的不同副本，避免把软件内部恢复和无关注册表类型差异误判成外部修改。快捷方式启动目标发生变化时仍拒绝覆盖，防止回退其他应用的更新。

## Explorer 绘制

- 原生模块升级为 1.1.0。导航栏按 TreeView 的 normal part/state 单独绘制背景；hot、selected、selected-not-focus、hot-selected 继续调用原绘制函数。
- 对作用域内的 `ETO_OPAQUE` 未选中文本背景补充处理，避免 GDI 文本绘制重新填白。
- 为原生预览宿主的空背景处理 `WM_ERASEBKGND`，并补齐状态栏和表头普通背景。文件预览器、RichEdit 文档内容不作整页覆盖。
- 卸载时移除窗口子类并重绘，恢复标题栏原属性；没有使用针对其他 Windows build 的硬编码对象偏移。

## 验证边界

验证包含前后端测试、实际 Windhawk 编译、隔离 Win32 窗口的像素和状态检查，以及打包桌面容器的统一入口测试。当前指针方案经过实际应用、撤销和初始恢复往返；测试外另有原始注册表快照与进程作业对象保护，结束后核对原指针设置和壁纸路径。

Explorer 的修复通过原生绘制函数与隐藏测试窗口验证；本轮没有在用户实际 Explorer 中注入新版 DLL。完整 Explorer 现场视觉验收和安装/卸载生命周期仍列为待验证，发布保持 prerelease。
