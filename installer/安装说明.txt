桌面主题工作室 0.2.0

支持 Windows 10（2004 / 19041 或更新）与 Windows 11 的 Intel / AMD 64 位电脑。

安装和程序启动都会请求 Windows 管理员授权。请核对程序名称后选择“是”；公共桌面快捷方式修改和运行组件需要这些权限。安装路径仍可自行选择，默认位于 Program Files。

图片与每个快捷方式独立对应：点击项目后选择图片，或从资源库拖图片到项目，再核对箭头两端后应用。图标修改前会自动备份。

“壁纸与视差”可以把图片、视频和全局鼠标视差应用到真实桌面，支持暂停、继续和停止恢复。关闭设置窗口后，已启用的背景和运行组件继续工作。

任务栏已按你的选择采用 Seelen Dock 和工具栏；Windhawk 使用匹配的原运行引擎编译并启用所选模组。可在同一页停用，实际运行状态单独显示。

安装包包含 Python 后端、Seelen/Windhawk 运行文件、离线编译工具和微软官方 WebView2 离线运行库，不需要 Node.js 或旧开发目录。共享的已有运行库会保留。系统需要 .NET Framework 4.8。

图文教程随程序离线安装。卸载前请恢复需要保留的图标/鼠标外观，停止桌面播放并停用组件。素材和恢复备份默认保留在用户数据目录。
