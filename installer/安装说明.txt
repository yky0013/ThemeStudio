桌面主题工作室 0.1.1

可用于 Windows 10（版本 2004 / 19041 或更新）和 Windows 11 的 Intel / AMD 64 位电脑。本安装包不面向 ARM 电脑。

安装路径可以在下一页选择。默认仅为当前用户安装，不需要安装 Python、Node.js 或旧工作台。

安装包包含微软官方 WebView2 离线运行库，只在检测到缺少时安装。已有的共享运行库不会被卸载。系统需要 .NET Framework 4.8。

安装后，右上角“图文教程”和开始菜单提供离线使用说明；开始菜单和 Windows“已安装的应用”提供卸载入口。

卸载只移除程序。素材、备份及当前外观会保留在用户数据目录中。想恢复原图标和鼠标时，请在卸载前使用程序中的恢复按钮。

当前可实际应用桌面快捷方式图标和系统鼠标方案。壁纸视差为页面预览，Seelen / Windhawk 的其他桌面引擎能力仍在整合中。
