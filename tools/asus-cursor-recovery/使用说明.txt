天选姬指针恢复（C# 原生版本，2026-10-20）

双击 AsusCursorRecovery.exe 即可。两个 BAT 入口仅为旧习惯保留，均直接运行同一个 EXE。
无需 PowerShell、Python、执行策略设置或管理员权限，使用 Windows 自带 .NET Framework 4.8。
先检查全部 13 个原厂指针文件；4 个原厂未定义角色使用 Windows 默认。
恢复前自动备份，写入或刷新失败时尝试回滚。
备份位置：%LOCALAPPDATA%\ThemeStudio-CursorRecovery\backups
不更改图标、壁纸或整套系统主题；ASUS 原厂素材仍由本机 Windows 提供，不随程序分发。

只读检查：AsusCursorRecovery.exe --verify-only
指定素材目录：AsusCursorRecovery.exe --cursor-directory "C:\Windows\Resources\Themes\ASUS"
自动验证：添加 --quiet --json-output "报告.json"，以退出码 0 表示成功、1 表示失败。
